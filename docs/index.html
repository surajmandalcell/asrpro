Product surface

Built like a desktop tool, not a prompt box.

ASR Pro keeps the daily flow tight: record a note, pick the right microphone, change models, reopen past transcripts, and know exactly where the app stores its data.

Fast capture

Start from the app, tray, or shortcut. The home screen stays focused on recording and the next useful action.

Transcript history

Search, copy, delete, reopen text files, and reprocess saved audio clips without turning notes into scattered files.

Model control

Technical read

Local-first engineering, visible product choices.

ASR Pro is an Electron desktop app with a React and Vite renderer. The important part is the product boundary: desktop capabilities stay behind the app preload API and transcription does not depend on a hosted speech service.

Runtime Electron shell with a Vite and React renderer for the working app UI.
Recognition Native Whisper transcription through @kutalia/whisper-node-addon and local GGML model files.
Storage Models, transcripts, recordings, config, logs, and cache live under app-owned storage paths.
Packaging Release workflow builds macOS, Windows, and Linux binaries through GitHub Actions and electron-builder.

What this proves

  • Product thinking beyond the recording button.
  • Clear boundaries between UI, desktop APIs, and native transcription.
  • Release and documentation workflows that match a real desktop utility.
