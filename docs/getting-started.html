First run guide

Getting started

Install ASR Pro, pick a microphone, choose a local Whisper model, and record a short clip. The app keeps speech, transcripts, and settings local unless you move them yourself.

Install

Start with a packaged release for the machine you are actually using.

step what to do
Download Open Releases and grab the package for your platform.
Place it Keep portable Windows and Linux builds in a folder you can move later with their sibling asrpro-data/ folder.
Open it Launch ASR Pro, then let the app create its local config, history, and model folders.

First run

  • open Sound and pick the microphone you want ASR Pro to use
  • open Models library and choose a Whisper model for local transcription
  • open Configuration for shortcuts, auto-copy, editor handoff, overlay placement, and launch on sign-in
  • return to Home when the input and model look right

Record and review

  • start recording from Home, the tray, or the keyboard shortcut
  • stop after a short sample so the first transcription finishes quickly
  • copy the transcript, open it in your editor, or send it through the history workflow
  • use History to search, reopen, delete, or reprocess saved clips

Keep it working

ASR Pro is designed for local, movable installs. The only maintenance step that usually matters is keeping the app and its data together.

case fix
Moving the app Move the executable or app bundle together with asrpro-data/. See Portable data.
Open on sign-in Turn on Launch at startup from Configuration. If the app moves later, toggle it off and on again from the new location.
Wrong microphone Refresh devices from Sound and pick the intended input again.
